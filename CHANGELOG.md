# Changelog

## 1.3 — First public beta

### Added

- Saved playlists with their own format, quality, and destination.
- Download new to queue new or missing files while skipping files already saved or queued.
- Multiple-link input with merged video IDs and per-link failure messages.
- Explicit in-app yt-dlp update checks and verified installation.
- Download overview with combined speed, progress, remaining files, approximate ETA, and free disk space.

### Included from earlier local builds

- Dark desktop interface and a download-folder prompt on first launch.
- Music, video, and full-playlist downloads.
- One to six concurrent transfers, pause, individual cancellation, and retries.
- Persistent library and duplicate detection by video ID and media type.
- Error messages that distinguish format, network, access, region, removal, and ambiguous availability failures.

### Distribution

The initial public package contains source and documentation. Portable binary distribution remains pending completion of third-party corresponding-source and notice packaging. Earlier 1.0–1.2 builds were local development builds, not public GitHub releases.
