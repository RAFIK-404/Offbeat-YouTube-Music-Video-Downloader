Ask on GitHub ↗
Is Offbeat really free?+

Yes. Offbeat is free and open source under the MIT License. The Windows app has no subscription or account requirement. You can also inspect the source code on GitHub.

What do I need to run it?+

A 64-bit Windows 10 or Windows 11 computer, an internet connection, and Microsoft Edge WebView2 Runtime. You do not need to install Python or use a terminal. First-time setup downloads the required tools from their official releases.

Which file do I download?+

Open GitHub Releases, expand Assets, and choose Offbeat-1.3.1-Windows-x64.exe for the current public beta. The source-code ZIP is for developers. The EXE is unsigned, so Windows may show an unfamiliar-app warning.

Can it download a complete playlist?+

Yes. Paste the playlist link, keep Full playlist checked, and choose MP3 or MP4. Offbeat can process several items at once. A failed item does not stop the remaining downloads.

How does duplicate skipping work?+

Offbeat checks the YouTube video ID and media type against your saved files and queue. Saving an MP3 still lets you save an MP4 of the same video. Different uploads of the same song count as separate videos; Offbeat does not compare audio fingerprints.

Why might a video fail to download?+

Private, removed, region-restricted, sign-in-required or bot-challenged videos may be unavailable. YouTube changes can also affect downloads. Try the in-app yt-dlp update check, or see the troubleshooting guide.

Does this website download videos?+

This is the home of the Offbeat Windows app. Downloads and conversion happen on your computer after you open the app. macOS and Linux builds are not currently available.
